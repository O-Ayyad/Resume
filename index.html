ChessOS

Operating system · C++ and assembly

A small 64-bit operating system that does one thing: play chess. It boots straight from a USB stick or virtual machine without Windows or Linux.

  • Own two-stage BIOS boot loader in x86 assembly: A20, memory map, VESA graphics, long mode.
  • Alpha-beta chess engine with a hash table, null-move pruning and a tuned evaluation at roughly 2,750 Elo.

SixDegrees.lol

Full-stack web app · live, in active development

Finds the shortest chain between any two Riot Games players through shared games, kills and assists, across every region except KR.

  • Indexes players by Riot PUUID, which stays the same across regions and games.
  • Graph built from months of crawling NA, KR, EUW, EUNE, BR and LAN matches, stored in Neo4j.
  • Works within a development API key's rate limits using a Redis-backed seed queue.
  • Python
  • FastAPI
  • Neo4j
  • Redis
  • Riot Games API
  • JavaScript
  • HTML/CSS
